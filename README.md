# راه‌اندازی سایت ریسورس‌پک بدوارز (نسخه‌ی بدون فایربیس)

چون فایربیس/گوگل‌کلاد از ایران در دسترس نیست، این نسخه به‌جاش از **خود گیت‌هاب**
به‌عنوان دیتابیس و فضای ذخیره استفاده می‌کنه. هیچ سرویس خارجی دیگه‌ای لازم نیست.

ساختار فایل‌ها:
- `index.html` → صفحه‌ی اصلی، اطلاعات پک‌ها رو از `data/packs.json` می‌خونه.
- `admin.html` → پنل مدیریت؛ با یک توکن گیت‌هاب وارد می‌شی و مستقیم به ریپو پوش می‌کنه.
- `js/config.js` → باید یوزرنیم و اسم ریپوت رو توش بنویسی.
- `data/packs.json` → لیست ریسورس‌پک‌ها (پنل مدیریت خودکار آپدیتش می‌کنه).
- `uploads/` → فایل‌های zip و عکس‌های بندانگشتی اینجا ذخیره می‌شن (پنل مدیریت خودکار می‌سازدش).

---

## ۱. پر کردن `js/config.js`

بازش کن و این سه مقدار رو با اطلاعات ریپوی خودت جای‌گزین کن:

```js
owner: "YOUR_GITHUB_USERNAME",
repo: "YOUR_REPO_NAME",
branch: "main",
```

## ۲. ساخت توکن دسترسی گیت‌هاب (Personal Access Token)

این توکن جای ایمیل/رمز فایربیس رو می‌گیره و کلید ورود به پنل مدیریته.

1. در گیت‌هاب برو به: **Settings (پروفایل خودت) → Developer settings → Personal access tokens → Fine-grained tokens**.
2. «Generate new token» را بزن.
3. در «Repository access» فقط همین یک ریپو رو انتخاب کن (نه همه‌ی ریپوها).
4. در «Permissions» بخش **Contents** رو روی **Read and write** بگذار (بقیه رو دست نزن).
5. یک تاریخ انقضا (مثلاً ۹۰ روز) انتخاب کن و توکن رو بساز.
6. توکن (که با `github_pat_...` شروع می‌شه) رو یه‌جای امن کپی کن — فقط یک‌بار نشونت می‌ده.

**نکات امنیتی مهم:**
- این توکن مثل رمز عبوره؛ جایی پابلیک (مثل کامنت، عکس، یا خود کد) ذخیره‌اش نکن.
- توکن فقط داخل مرورگرت (در `sessionStorage`) نگه داشته می‌شه و با بستن تب پاک می‌شه — هر بار باید دوباره واردش کنی.
- اگه فکر کردی لو رفته، از همون صفحه‌ی توکن‌ها می‌تونی Revoke (لغو) کنی.

## ۳. آپلود فایل‌ها روی گیت‌هاب

همون مراحل قبلی: از طریق **Add file → Upload files** در ریپوت، تمام فایل‌های
این پوشه (با همون ساختار `css/`, `js/`, `data/`) رو آپلود و Commit کن.

## ۴. فعال‌سازی GitHub Pages

**Settings → Pages** → Source را روی شاخه‌ی `main` و پوشه‌ی `/ (root)` بگذار.

## ۵. استفاده از پنل مدیریت

1. برو به `admin.html` روی سایتت.
2. توکنی که در مرحله‌ی ۲ ساختی رو وارد کن.
3. فرم «افزودن ریسورس‌پک» رو پر کن و فایل zip (و عکس دلخواه) رو انتخاب کن.
4. بعد از زدن «افزودن به فروشگاه»، یک کامیت خودکار روی ریپوت ثبت می‌شه و فایل‌ها
   داخل پوشه‌ی `uploads/` می‌رن. صفحه‌ی اصلی هم خودکار آپدیت می‌شه (ممکنه چند
   ثانیه طول بکشه تا GitHub Pages تغییرات رو منتشر کنه).

## محدودیت‌ها

- هر فایل (zip یا عکس) باید کمتر از **۲۵ مگابایت** باشه — این محدودیت خودِ
  GitHub API هست. برای ریسورس‌پک‌های معمولی معمولاً کافیه؛ اگه فایلت بزرگ‌تره،
  بهتره فشرده‌ترش کنی یا با Git LFS جدا آپلودش کنی.
- حذف یک پک از پنل، فقط از لیست سایت حذفش می‌کنه؛ خود فایل zip در ریپو
  می‌مونه (حجم رایگانه، اشکالی نداره، فقط بدون که کاملاً پاک نمی‌شه).
- چون دیتابیس واقعی نیست، اگه دو نفر همزمان از پنل آپلود کنن ممکنه یکی از
  تغییرات گم بشه. برای یک نفر مدیر (خودت) مشکلی پیش نمی‌آد.

## تست لوکال (اختیاری)

```
npx serve .
```

(باز کردن مستقیم `index.html` با دابل‌کلیک هم تا حدی کار می‌کنه، ولی بعضی
مرورگرها fetch فایل‌های لوکال رو محدود می‌کنن — بهتره با سرور بالا تست کنی.)
